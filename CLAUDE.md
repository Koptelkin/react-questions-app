# CLAUDE.md — react-questions-app

## Стек проекта (отличается от глобальных настроек)
- Чистый JavaScript, без TypeScript.
- Состояние только через хуки React (`useState` и кастомные хуки), без Redux Toolkit.

## Архитектура
- Актуальная архитектура описана в [docs/architecture.md](docs/architecture.md).
- Когда в разговоре меняется архитектура (дерево компонентов, папки, состояние, решения по открытым вопросам), сразу обнови `docs/architecture.md`, чтобы он оставался актуальным. Отдельно спрашивать разрешение на это не нужно.
- Закрытые открытые вопросы отмечай в файле и переноси решение в соответствующий раздел.
